## 📌 Project Overview

The project focuses on analyzing damaged Brahmi stone inscriptions using **Deep Learning** and **Computer Vision** techniques.

An **Enhanced MobileNet-based approach** is used for recognizing and analyzing damaged Brahmi inscription characters and assisting in the restoration and interpretation of historical text.

## 🔬 Key Technologies & Areas

- Deep Learning
- Computer Vision
- Enhanced MobileNet
- Image Processing
- Brahmi Script Recognition
- Text Analysis
- Historical Inscription Restoration
